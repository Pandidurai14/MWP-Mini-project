# 📄 Personal Resume Builder

**A Personal Resume Builder using HTML5 and CSS3**

Build your professional resume instantly — fill the form on the left and watch your resume update live on the right. Download or print it as a clean PDF with one click.

---

## ✨ Features

- 📝 **Simple Form** — Name, career objective, education, skills, experience and projects
- 👀 **Live Preview** — Resume refreshes in real time as you type
- ⬇️ **Download / Print** — Print-friendly CSS hides the form and exports only the resume
- 📱 **Responsive Layout** — Works on desktop, tablet and mobile
- 🎨 **Modern UI** — Gradient header, skill chips, smooth animations

## 🛠️ Technologies Used

| Technology | Purpose |
|------------|---------|
| **HTML5** | Semantic structure (`<header>`, `<section>`, `<fieldset>`, `<article>`, `<footer>`) |
| **CSS3** | Variables, Flexbox, Grid, Media Queries, Gradients, Animations, Print CSS |
| **JavaScript** | Minimal script for live preview updates |

## 📂 Project Structure

```
├── index.html    # Main page - form + resume preview
├── style.css     # All styling (CSS3)
├── script.js     # Live preview update logic
└── README.md     # Project documentation
```

## 🚀 How to Run

1. Download or clone this repository
2. Open `index.html` in any modern web browser
3. Fill in your details — the resume updates instantly
4. Click **⬇ Download / Print** to save it as a PDF

```bash
git clone https://github.com/kit2824bcs019-glitch/DS-Mini-project-.git
cd DS-Mini-project-
start index.html
```
